# Audio overrides

All sounds are synthesized at runtime. To use recorded audio, place an `.ogg` (or `.wav`) file here named exactly after the sound; it is picked up automatically, no code changes needed.

Format: mono, 44.1 kHz. Looping ambience files should be seamless and set to loop on import.

Names:
amb_desert, amb_forest, amb_mountain, wind, rain, night, heartbeat, step_sand, step_grass, step_snow, step_human, drink, eat, dig, jump, swipe, hit, trap_snap, gunshot, thunder, roar, bear_growl, leopard_growl, howl, snort, fox_bark, bleat, whistle, shikari_shout, shikari_whistle, chime, click, bird

Example: `assets/audio/gunshot.ogg`. Record in Audacity, normalise to -3 dB, export Ogg Vorbis.
